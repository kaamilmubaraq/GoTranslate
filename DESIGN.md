# GoTranslate design system

A light workspace for people reviewing Japanese documents at a desk in daylight. White document surfaces and neutral gray controls keep long passages readable. The existing brick-red accent is reserved for primary actions and selected controls.

- Typography: system sans-serif; Japanese text uses the platform Japanese sans-serif fallback. Body text 16px, document text 17px with generous line spacing.
- Colors: ink #20242c, secondary text #59616d, canvas #f5f6f8, surface #ffffff, divider #dce0e5, accent #b6382d.
- Layout: compact header, 300px document settings sidebar, flexible results workspace. Stack at 900px.
- Components: 8px control radii, 12px panel radii, solid borders without decorative shadows; semantic native form controls.
- States: visible keyboard focus, inline errors and warnings, indeterminate processing state, actionable empty results, reduced motion.
